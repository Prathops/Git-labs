# Trainee Frontend Interface

## Project Information
This is the static HTML frontend for the trainee project. It acts as the user interface for our application.

## How to Run
1. Navigate to this folder in your terminal.
2. Start a quick local Python web server by running: `python3 -m http.server 3000`

## How to Test
Open a web browser and go to `http://localhost:3000`. You should see the "Welcome to the Trainee Frontend" heading displayed on the page.
