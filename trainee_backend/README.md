## Project Information
This is the backend service for the trainee project, built using Node.js. It acts as the server-side component for our application.

## How to Run
1. Ensure Node.js is installed on your system.
2. Run `node server.js` to start the application.

## How to Test
Once the server is running, you can test it by opening a terminal and running:
`curl http://localhost:8080`
